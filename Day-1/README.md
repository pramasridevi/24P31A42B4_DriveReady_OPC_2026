# Day 1 – Introduction to Agentic AI

## Overview
Day 1 focuses on building a basic AI-powered shopping assistant for **Kiran Shop** using Python, LangChain and Groq LLM.

The assistant helps customers with product-related enquiries, including product availability, prices, offers and orders. It follows predefined system instructions to provide polite, simple and customer-friendly responses.

## Objectives
- Understand the fundamentals of LLM-powered applications.
- Integrate Groq LLM using LangChain.
- Create and configure system prompts.
- Build a basic AI shopping assistant.
- Understand the importance of responsible AI responses.

## Technologies Used
- Python
- LangChain
- LangChain-Groq
- Groq API
- Google Colab

## Implementation
1. Installed and imported the LangChain-Groq library.
2. Configured the Groq API key using Google Colab Secrets.
3. Initialized the `ChatGroq` model using `openai/gpt-oss-120b`.
4. Designed a system prompt defining the role and responsibilities of Kiran Shop's AI assistant.
5. Created an `ask()` function to send customer questions to the LLM.
6. Explored prompt safety using the Llama Prompt Guard model.

## Key Learnings
- Working with Large Language Models (LLMs).
- Connecting Python applications with Groq.
- Writing effective system prompts.
- Generating context-aware AI responses.
- Understanding prompt injection and AI safety.

## Project Outcome
Successfully developed a basic AI-powered shopping assistant that responds to customer enquiries using predefined instructions.

## How to Run
1. Open the Day-1 notebook in Google Colab.
2. Install the required dependencies.
3. Add your Groq API key to Colab Secrets.
4. Execute the notebook cells sequentially.
